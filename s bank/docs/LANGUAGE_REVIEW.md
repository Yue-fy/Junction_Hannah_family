# Language review: key terms in EN / FI / SV

This is for a native Finnish and a native Swedish (Finland-Swedish) speaker to approve. Each row is one concept, and each concept uses one term everywhere: web copy, server answers, year cards and the coach. The wording follows Finnish bank apps (S-mobiili, OP, Nordea): short, plain and in the second person. Please mark rows OK or suggest a better word.

Formats: FI/SV money `1 138,27 €`, whole euros `2 365 €` (no-break spaces); EN `€1,138.27`. Percentages FI/SV `9,6 %`, EN `9.6%`. FI/SV dates `5.8.2026`. VAT rates FI `13,5 % ja 25,5 %`, SV `13,5 % och 25,5 %`.
