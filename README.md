## Teammates: get started (about 10 minutes)

1. Accept the collaborator invite (check your email or github.com/notifications).
2. Clone the repo and open it:
   ```bash
   gh auth login
   gh repo clone Yue-fy/Junction_Hannah_family
   cd Junction_Hannah_family
   ```
3. Start your coding agent in the repo root.
   - **Claude Code**: run `/onboard`
   - **Other agents**: say *"Read AGENTS.md, then follow .claude/skills/onboard/SKILL.md"*
4. On GitHub, click **Watch → All Activity** on this repo and turn on push notifications in the GitHub Mobile app.
   The captain posts announcements in issue #1.
